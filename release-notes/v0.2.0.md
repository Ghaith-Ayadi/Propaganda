# v0.2.0

October 11, 2026 · The first numbered release

- **Getting started.** A new tenant's first day, from a few answers to a first published article: the Strategist proposes a plan, the Pitcher pitches, the Writer drafts.
- **The Strategist.** It plans with your answers instead of asking again, carries earlier rounds into a revision, and says which searches it proposes and why. Its questions block approval until you answer them.
- **Live updates.** Strategist proposals, pitches and drafts in review show up without a refresh.
- **Editor.** Changes made elsewhere to the post you have open now show up.
- **Knowledge base.** The Checker and the Guardian are on for every new tenant.
- **Admin.** Runs show their steps live and say when a run is inside a long step; Admin moved under Settings.
- **Behind the scenes.** Every model call's input and output is kept for Propaganda Labs, operators get a read-only role, a tenant can be suspended so it makes no paid call, and releases now run the test suites and the real-model tests before anything ships.
