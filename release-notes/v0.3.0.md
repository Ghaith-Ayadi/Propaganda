# v0.3.0

October 15, 2026 · Comments, strategy review and the model switch

- **Comments.** Select text in a post and leave a comment on it, or leave a general comment. Threads sit beside the writing. Pitches have the same highlight-to-comment in a larger dialog, with narrower comment windows and a cap on how much of the quote is kept.
- **Strategy.** The feedback box is always visible and you can approve at any point. If you leave with feedback you have not sent, you get a warning instead of losing it.
- **Models.** The Strategist runs on Opus 5.5, and the first pitches run on Sonnet 5.5. The Strategist's follow-up and retry calls reuse the prompt it already sent.
- **Writer.** The default voice varies paragraph length, writes in a higher register, varies how paragraphs open, spreads the evidence through the post and writes sentences with more substance. A draft gets one short description, used as both the subtitle and the excerpt, and the body no longer repeats it.
- **Sources.** The Pitcher and the Writer cite only sources with authority. An unknown site gets a quick check that it is citable and about the topic, and when nothing citable turns up, one search aimed at studies, analyst firms and major press runs and is checked the same way. The first-day topic pitches follow the same rule.
- **App.** The drawer collapses and the details panel resizes. The Propaganda icon is now the tab and installed-app icon, padding fits laptop screens, and text weights stop at 600. Published blog themes go lighter under that weight cap. Tabs, the drawer, the details panel, board and table rows, comments and new chat messages now move with short transitions, and they hold still for anyone who asks for reduced motion.
- **Arena.** The address `arena` is reserved so no tenant can take it.
- **Operations.** A scoped write role with an audit log is in place for urgent one-off fixes, so they no longer need the full service key.
- **Schema.** Three additions: the comments table, the reserved address and the hotfix role. Nothing existing is changed or removed.
