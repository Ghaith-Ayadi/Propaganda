# v0.5.0

October 24, 2026 · Search Console in the plan and the pitches, a Selected stage, previews and steadier drafting

- **Search Console, every week.** For blogs we host, the plan and the pitches now read the searches your blog already gets. The searches table in Goals is redesigned: four two-line cells under bucket headers, so a row reads at a glance. The numbers are kept weekly, for trends later.
- **A Selected stage.** The pipeline has a stage for posts you picked. We start the writing the moment you select a post, and when you send a draft back, so a post cannot get stuck between the two.
- **Preview before you publish.** An unpublished post opens at a preview address that only your team can see, and search engines are told to skip it.
- **Steadier drafting.** Your own voice goes over the craft rules, and code measures the rhythm of a draft. Write now retries a run that died, and a draft started during setup now lands in the right post.
- **Dates search engines can trust.** A post's "updated" date on the blog, in the sitemap and in the feed moves only when its title, subtitle, excerpt or text changes, and no longer when you favourite it or move it.
- **Chat and phone.** Chat shows your conversation after a refresh. On a phone the posts list, the New post button, the agent rules dialog and sign-in load are fixed. A selected row no longer covers its card's border. Signing in from Claude no longer shows a "site not found" page.
- **Safer by default.** Members can write only the fields they are meant to write on six tables that had inherited wider access.

The schema gains a content date on posts, a weekly Search Console table and a new model price, and it closes the default grants on six tables. No data is changed or removed.
