# v0.5.0

October 24, 2026 · Search Console in the plan and the pitches, a Selected stage, previews and a steadier Writer

- **Search Console, every week.** For blogs we host, the plan and the Pitcher now read the searches your blog already gets. The searches table in Goals is redesigned: four two-line cells under bucket headers, so a row reads at a glance. The Search Console numbers are kept weekly so a trend can be drawn.
- **A Selected stage.** The pipeline has a stage for posts you picked. The worker records approvals and send-backs itself, so a post cannot get stuck between the two.
- **Preview before you publish.** An unpublished post opens at its preview address on the app host.
- **A steadier Writer.** Your own voice goes over the craft rules, and code measures the rhythm of a draft. Write now retries a run that died, and a day-one draft that was approved mid-run fills in the post the approval made.
- **Dates search engines can trust.** A post's "updated" date on the blog, in the sitemap and in the feed moves only when its title, subtitle, excerpt or text changes, and no longer when you favourite it or move it.
- **Chat and phone.** Chat shows your conversation after a refresh. On a phone the posts list, the New post button, the agent rules dialog and sign-in load are fixed. A selected row no longer covers its card's border.
- **Safer by default.** Members can write only the fields they are meant to write on six tables that had inherited wider access. The app's service worker leaves the worker API and sign-in discovery to the network.

The schema gains a content date on posts, a weekly Search Console table and the price of Opus 5.5, and it closes the default grants on six tables. No data is changed or removed.
