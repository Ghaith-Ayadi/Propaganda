# v0.4.1

October 22, 2026 · Writing starts again, and a sharper plan

- **Approve works when the request is held back.** A request that was refused before it reached us is retried once, and the error now says what happened instead of failing without a word.
- **Write now.** Posts that are waiting to be written read as tasks, with their planned date, a Write now button on each and Write all now on the column. A post started by Approve or by "We draft it" counts as started.
- **Getting started.** Once every first pitch is reviewed, you are guided to the next step.
- **Real searches in the plan.** For blogs we host, the plan reads the real searches your blog already gets.
- **A sharper plan.** Named competitors are looked up, the limits behind each number are stated, a revision reuses the data it already has, and growth is compared with the same months last year.

No data is changed or removed, and there are no schema changes.
